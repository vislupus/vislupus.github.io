中国を訪れるのはずっと私の夢でしたが、遠すぎるし、行くのはとても大変だろうとずっと思っていました。マルコ・ポーロは往復に何年もかかったのです。もちろん今は飛行機がありますが、それでも地球の反対側です。それでも11月の初め、私は行かなければと決心しました。少林寺やカンフー映画を見て育った私は、どれほど遠くても、どうしても行きたかったのです。数日かけていろいろな旅行会社のプランを調べ、見たい場所ができるだけ多く含まれているものを選びました。あとは半年待つだけ――でもそれは、どんな旅になるのかを半年間夢見ていられるということでもありました。

そして旅は素晴らしいものでした。2026年5月3日から13日までの11日間を中国で過ごし、北京、少林寺、西安、桂林、上海を巡りました。何度でも戻りたい場所のひとつで、これからも長いあいだ夢に見続けることになりそうです。

::: curious
**数字で見る中国**

- 人口は約14億人。長いあいだ世界一の人口大国でしたが、2023年にインドに抜かれました。
- 面積は960万km²で、ブルガリアのほぼ87倍です。
- 公式に認められた民族は56あり、そのうち漢族が91%以上を占めます。
- 国土は東西に5つのタイムゾーンにまたがっていますが、国全体がひとつの標準時（UTC+8）で暮らしています。ブルガリアとの時差は、冬は6時間、夏は5時間です。
:::


## 出発の前に

旅の話を始める前に、もし皆さんも中国へ行くことにしたら知っておくと役に立つことをいくつか紹介します。

::: warning
**薬物とギャンブル。** 中国の薬物とギャンブルに関する法律は非常に厳格です。薬物の所持や使用は重く罰せられ、密売・製造・流通に関わる重大な犯罪では死刑になることさえあります。

ギャンブルも中国の大部分で禁止されており、違反すると高額の罰金や懲役を科されることがあります。面白い例外がマカオで、ここではカジノが合法で、ギャンブル産業が非常に発達しています。
:::

::: warning
**出国禁止。** 中国では、地元の当局や市民との間に未解決の法的・金銭的な問題があると、出国しようとした際に出国を拒否される可能性があります。

これは、裁判沙汰になった未払いの借金、係争中の訴訟、捜査、その他の重大な法律違反がある場合に起こり得ます。このような場合、当局は問題が解決するか制限が解除されるまで、出国禁止措置をとることができます。

最悪なのは、空港に着くまでそのような禁止措置があることすら知らない場合があることです。そして問題の解決には数か月、時には数年かかることもあります。
:::

::: tip
**インターネットとアプリ。** 中国では、VPNや海外の通信会社のSIM／eSIMカードがないと、欧米のサイトやアプリ（Google、WhatsApp、Instagram、Facebookなど）は使えません。ただし、これらがあってもスマートフォンによっては使えないことがあるので、必要なものを事前に確認するか、現地で自分の機種に対応したeSIMを手に入れてください。

私が話した人はほぼ全員、WeChatでやり取りしていました。ViberやWhatsAppのようなものですが、機能はずっと多く、中国の人たちは支払いも含めてほとんどすべてにこれを使っています。

AlipayやWeChat Payを使うにはインターネットが必要です。2023年からは、どちらのアプリにも海外のVisaやMastercardを登録できるようになり、少額の支払い（200元未満）なら通常は手数料もかかりません。ただ実際には、私たちのカードが通らないこともありましたし、一部の機能（たとえば個人間の送金）には中国の銀行口座が必要です。
:::

::: tip
**現金も持っていきましょう。** ほかに支払い手段がない場所に行き当たるかもしれません。ネットでは中国ではもう紙幣は使われていないとよく書かれていますが、それは違います。現金で支払っている地元の人をたくさん見かけました。
:::

::: warning
**パスポートは常に携帯しましょう。** 中国ではパスポートを常に持ち歩かなければなりません。警察がいつでも提示を求めることができるからです。それに、ほとんどの博物館や観光地にはパスポートで入場します。
:::

::: note
**お金について少し。** 100人民元（CNY）は約13.4ユーロです（2026年11月の為替レート）。比較のために言うと、2025年の中国の都市部における民間部門の平均月給は約800ユーロでしたが、ブルガリアでは2026年第2四半期に1,444ユーロ、つまり約80%高い水準でした。

農村部の1人当たり平均可処分所得――子どもや年金生活者、農業やその他の収入を含めたもの――を見ると、月約273ユーロです。

中国の生活費がどれだけ安いかは、誰に聞くかで大きく変わります。生活費比較サイトの結果はまったくばらばらで、中国はブルガリアより4分の1ほど安いとするサイトもあれば、むしろ少し高いとするサイトもあります。それらの数字によれば、北京や上海のような大都市はソフィアとほぼ同じくらいで、小さな都市はかなり安くなります。
:::


## 北京

一晩中飛行機に乗って、ようやく北京に着きました。私たちを出迎えたスタッフのグループがどこに並ぶかを案内してくれて、私たちはすぐに、旅のあいだずっとつきまとうことになるもの――秩序――を感じました。その後、空港や駅でも同じことを目にしました。中国ではすべてがよく油を差した機械のように動き、すべてがちょうど必要なときに起こるのです。出発時に見たイスタンブール空港とはまるで正反対でした。

最初は、警察官が立って私たちを見ていることや、どこにでもカメラがあることが奇妙に感じられましたが、数日で慣れて気にならなくなりました。ただ、ずっと理解できなかったのは、スクーターが道路や歩道を猛スピードで走り回ることが許されている理由です。彼らにはルールがなく、法律の上にいるような気がしました。荷物を時間どおりに届けなければならないからだとは思いますが、それにしても彼らの走り方は普通ではありません。それでも、タイに比べれば状況は何倍もましです。

初日の夜、ホテルのまわりを散歩してみることにしたのですが、一番驚いたのは、中国がどれほど近代的で、同時にどれほど伝統的かということでした。大通りの片側には高級車が前に並ぶ巨大なショッピングモールがあり、反対側には伝統医学の薬局がある、といった具合です。最初は驚きましたが、その後の数日間どこでも同じ光景を目にして、すっかり慣れてしまいました。

### 天安門広場

この日はとても早く始まりました。できるだけ早く広場に着かなければならず、10分遅れただけでも後で何時間も行列に並ぶことになりかねないと言われていたからです。まだ人が少ないうちに間に合って入れましたが、本当に私たちのわずか20分後には大混雑になり、早く来てよかったと心から思いました。

::: warning
中国ではどこにでもカメラと警察がいて、通りや建物の中で起こることはすべて監視されています。それが最もよくわかるのが、まさにこの天安門広場です。
:::

この広場は中国の権力が集まる場所です。紫禁城（北）から時計回りに、中国国家博物館（東）、毛主席紀念堂（南）、そして中国の国会が開かれる人民大会堂（西）が並んでいます。天安門という名前は「天の平和の門」という意味で、これは有名な毛沢東の肖像画が掲げられている紫禁城の門の名前です。1989年春の抗議活動がここで起きたのも、まさにこの場所の象徴性ゆえでした。

本当に驚いたのは、中国人がとても多く、外国人はほとんどいなかったことです。その後の数日間も、ほとんどどこでも同じで、観光地の訪問者の80〜90%ほどが地元の人でした。中国は距離がとても大きいので、他の省の人でさえ外国から来た旅行者のようなもので、彼らにとって首都を訪れるのは特別な体験なのです。

そこでとても心に残る出来事がありました。写真を撮りながら歩いていると、6歳くらいの男の子が近づいてきて、何度か意思疎通を試みた末に、私と一緒に写真を撮りたいのだとわかりました。地元の人が私と写真を撮りたがるなんて、それまで一度もなかったことです――しかも中国のど真ん中で。国の奥地の観光地でない地域の人々は外国人を見ることがめったになく、外国人が現れるとちょっとした事件になると聞いたことはありましたが、実際に体験したことはありませんでした。それは一度きりではなく、その後も人々がただ近づいてきて、一緒に写真を撮ってほしいと頼んでくることがありました。

私が一番よく聞かれる質問のひとつは、中国人はどんな人たちかということです。正直に言って、とても良い印象を持って帰ってきました。私が外国人だから、もてなそうとしてくれたのかもしれませんが、私にとって中国人は、かなり厳しい環境で暮らし、歴史的に多くの国に踏みにじられ辱められながらも、人間らしさを失わなかった善良な人々です。もちろん人口は膨大なので、外国人をだまして得をしようとする人は必ずいますが、全体としては親切で温かい人たちです。

### 紫禁城

紫禁城は映画で何度も見てきましたが、実際にそこで撮影された映画はそれほど多くありません。最も有名なのは「ラストエンペラー」（1987年）で、宮殿の中での撮影を許された最初の西洋の長編映画です。今ではほとんどの作品が別の場所で撮影され、宮殿はCGで付け加えられるか、リアルなセットが使われます。「中国のハリウッド」と呼ばれる横店には、紫禁城の実物大のレプリカまであるのです。そして中国で俳優をするのは素晴らしいことだと思ったら、考え直したほうがいいかもしれません。多くの俳優（特にエキストラ）は昼間は映画やドラマに出演し、夜は料理の配達をしていると聞きました。この職業だけで生計を立てるのは難しいからです。

宮殿そのものは明の永楽帝の時代、1406年から1420年にかけて建てられ、500年近くにわたって明と清の皇帝たちの住まいでした。「紫禁」と呼ばれるのは、皇帝の許可なしには誰も入ることも出ることもできなかったからです。

よく見ると、殿舎の中はほとんど空っぽで、装飾もなく家具もほとんどないことに気づくでしょう。私たちが聞いた理由はこうです。1948〜1949年の国共内戦の際、蒋介石の国民党政府が皇室コレクションの貴重な品々を何千点も台湾へ運び出しました。現在それらは台北の国立故宮博物院に収蔵されています。

ただし、すべてを持ち出したわけではありません。戦争中に疎開させた約13,000箱のうち、台湾に渡ったのは2,972箱です。紫禁城の博物館には今も180万点以上の収蔵品があり、その大部分は宮殿の殿舎ではなく、収蔵庫や展示室にあるだけなのです。
:::

目についたのは、あちこちで敷石が穴だらけで、建物の塗装がはげていることでした。どこかに腐った板がぶら下がっていても驚かなかったでしょう。紫禁城は本物らしく見えるように、あえて改修していないのだと聞きました。それにしても、中国最大の観光地のひとつが歩くのに危険で、穴で足をくじかないようにずっと足元を見ていなければならないのは不思議です。後で知ったのですが、実際には宮殿は修復されているものの、それは選択的に行われています。できるだけ多くのオリジナルの素材を残そうとしているうえ、規模があまりに大きいので、一度にすべてを修理することはできないのです。

それでも一番印象に残ったのは、王女や皇后の伝統衣装を身にまとい、あちこちで写真を撮りながら歩いている女の子たちでした。ときどき、本物の王女たちがここを歩いていた数百年前にタイムスリップしたかのような気分になりました。ただ今の彼女たちは、SNS用の完璧な写真スポットを探しているのですが。

{% figure "images/china/IMG_20260504_095605.jpg", "紫禁城で清朝時代の衣装を着た女の子たち" %}

その後の数日間、伝統衣装の女の子たちをほとんどどこでも見かけましたが、面白いことに衣装は地域によって変わりました。紫禁城では主に最後の王朝である清のスタイル、西安では唐のスタイル、桂林周辺では地元の少数民族の衣装でした。

皇帝の宮殿での暮らしがどんなものだったか興味がある方には、アニメ「薬屋のひとりごと」をおすすめします。主に唐の時代に着想を得た架空の帝国が舞台なので歴史的に正確ではありませんが、宮廷で人々がどう暮らし、どんな陰謀が渦巻いていたかがとてもよく描かれています。紫禁城そのものを舞台にした作品を見たいなら、ドラマ「瓔珞（エイラク）〜紫禁城に燃ゆる逆襲の王妃〜」がおすすめです。清の乾隆帝の時代の物語です。

### 真珠工場

中国で「工場」を訪れると言われたら、おそらくショッピングモールの中にある店に連れて行かれ、品質を国が保証しているから――と彼らは請け合いますが――値段はかなり高めだと思っておいてください。

私たちの体験もまさにそうでした。店に連れて行かれ、まず真珠がいかに素晴らしく、信じられないほど価値があり、絶対に買うべきかを長々と説明されました。こうした店では値切るのは一般的ではありませんが、多少の割引には応じてくれるかもしれません。

真珠は本当にとても美しいのですが、今では大量に生産されていて、ほとんどは安価なものです。中国の多くの場所で本物の真珠だと言われますが、ほとんどの場合は偽物か、低品質の真珠をとても珍しいものとして売りつけられます。それでも真珠を買いたいなら、こうした店のほうが安全です。

### オリンピック公園

これらの観光地を巡ったあと、ガイドが特別な場所を用意してくれていて、2008年のオリンピックのために造られたオリンピック公園に連れて行ってくれました。そこには、私たちが大会の記憶とともに思い出す象徴的な建物があります。「鳥の巣」として知られる国家体育場、「ウォーター・キューブ」こと国家水泳センター、そして大会中にテレビスタジオが置かれた玲瓏塔です。少し先には、2015年にオープンした高さ258メートルのオリンピックタワーがそびえています。全体として散歩にぴったりの場所ですが、見た目は近そうでも実際の距離はかなりあります。訪れる価値は十分にあります。

中国人は数字の4を不吉だと考えると聞いていました。「死」を意味する言葉とほとんど同じ発音だからです。でも、4階や4のつく部屋がまったくないホテルがあるとは信じていませんでした。ところが本当で、上海のエレベーターには4階のボタンが本当にありませんでした。

一方、8は富や成功、繁栄の象徴です。発音が「財を成す」という意味の言葉に似ているからです。北京オリンピックが2008年8月8日のちょうど20時08分に開幕したのはそのためです。
:::

### 北京動物園

気持ちのいい散歩のあと、本物のパンダが見たくなって北京動物園に行きました。ここには数頭のパンダとたくさんの動物がいます。全体として散歩には楽しい場所ですが、パンダが見たいのでなければ、わざわざ予定に入れるほどではないと思います。世界の他の場所で見られないような本当に珍しい動物はいませんし、それほど広くもありません。私にとっては少し期待外れでした。パンダに近づくことはできず、見られた2頭はガラス越しで、30分並んだあげく、もう遅すぎてパンダは寝てしまったと言われたのです。

{% figure "images/china/IMG_20260504_153258.jpg", "注目を一身に浴びてご満悦のパンダ" %}

::: curious
海外の動物園にいるジャイアントパンダは、ほぼすべてが中国の所有です。他の国はパンダを買うことはできず、通常10年間の特別な協定を結ばなければなりません。動物園はパンダ1組につき年間約100万ドルを支払い、海外で生まれた子どもも中国の所有のままで、2〜4歳になると中国に返されます。

パンダは外交でも重要な役割を果たしています。中国はパンダを友好と良好な関係の象徴として利用しており、関係が悪化すると協定の更新を拒んだり、返還を求めたりすることがあります。それは重大な外交上のシグナルと受け止められます。

つまり、この愛らしい白黒のクマたちは単なる観光の目玉ではなく、世界中に派遣された中国の大使でもあるのです。
:::

### 北京ダックの夕食

一番印象に残ったことのひとつが、中国人の食事のスタイルでした。伝統的にはテーブルにたくさんの料理が並び、みんながそれぞれ少しずつ取ります。今ではそんな時間のある人はあまりいませんが、祝日に全国から親戚が集まるときには、今でもたくさんの料理を作って盛大なごちそうを並べます。

ただ、今では多くの人がネットで料理を注文するほうを好みます。数分で届くので、ほとんど手間をかけずに伝統的なごちそうをそろえることができ、しかも一番面白いのは、値段がかなり手頃なことです。だから料理ができない人も多く、たぶんしたいとも思っていないのでしょう。そもそも中国では、ほとんど何でもネットで注文できます。

{% figure "images/china/IMG_20260504_175912.jpg", "料理がずらりと並んだ伝統的な食卓" %}

北京ダックを、詰め物をしたアヒルや、変わった甘酢ソースのかかったアヒルだと想像しているなら、それはまったくの誤解です。主役はパリパリの皮で、アヒルを特別な方法で乾燥させ、つやを出して焼き上げ、薄く切り分けます。小さな薄い餅（皮）と野菜、そして素晴らしい黒っぽいソースと一緒に出され、皮にアヒルと野菜をのせて巻き、ソースにつけて食べます。とてもおいしいのですが、かなり脂っこくて重たいです。

::: curious
中国人は全体的に、私たちよりずっと砂糖を摂りません。彼らのお菓子は私たちにはほとんど味がしないように感じられるので、中国のお菓子をお土産に持ち帰って、みんなに全然甘くないと言われても驚かないでください。それも中国料理の一部なのです。
:::

### 朝陽公園

ふつうなら、いろいろな体験をした長い一日のあとは横になって休みたくなるものですが、私はホテルからとても近そうに見えた公園に行ってみることにしました。ただ、中国の距離はとても大きく、その「近くの小さな公園」は5km先だったのです。その代わり、地元の人たちが夜に何をしているのかを見ることができました。

公園ではジョギングをする人や犬の散歩をする人がいて、特に変わった様子はありませんでした。ところが歩いていると、空に何かが光っているのが見えました。ドローンかと思ったら、糸に沿って小さなライトをつけた凧で、空に光りながら浮かんでいたのです。かなり人気のある趣味のようで、オリンピック公園でも見かけましたし、その後の数日間にも目にしました。

{% figure "images/china/IMG_20260504_201018.jpg", "夜空に光る凧" %}

ふと音楽が聞こえてきたので、何が起きているのか見に行くことにしました。プロヴディフの「歌う噴水」のようなものを想像していたのですが、それよりずっと面白いものでした。湖のほとりに若者たちが集まって歌っていたのです。コンサートでもあるのかと思いましたが、ステージも歌手もおらず、ただみんなで一緒に歌っているだけでした。英語を話せる人を長いこと探して（これは中国では難しいことです）、ようやく見つけた女の子が説明してくれたところによると、前日に「鳥の巣」で台湾のロックバンド、五月天（Mayday）のコンサートがあったそうです。このバンドは中国で絶大な人気がありますが、私はそれまで聞いたこともありませんでした。

{% video "images/china/VID_20260504_203510.mp4", { caption: "大好きな曲を歌う若者たち" } %}

彼女は、私も気になっていた湖の中の不思議な光る球が何なのかも説明してくれました。それはバンドメンバーのマスコットで、それぞれの色が5人のメンバーの1人ひとりを表しているのだそうです。後で知ったのですが、この巨大なバルーンは彼らのコンサートに合わせて公園の湖に登場するもので（初めて設置されたのは2025年夏）、今回は私たちが到着する2週間ほど前に設置されたそうです。2026年5月、五月天は北京でなんと12回のコンサートを行い、65万人近くが詰めかけました。

{% figure "images/china/IMG_20260504_203155.jpg", "湖に浮かぶ5つの光るバルーン――五月天のメンバー1人にひとつずつ" %}

{% youtube "GtDRcXtDg-4", "五月天の代表曲のひとつ「突然好想你」" %}

私はこの女の子と何時間も話しました。彼女の生活や私の生活のこと、中国とブルガリアの違いについて。一番驚いたのは、自分が中国についてどれほど間違ったイメージを持っていたかということでした。私は中国を、人々が押しつぶされ、権力者に逆らうことを言えば刑務所に入れられるか路上で殺される、絶対的な独裁国家だと思っていたのです。この若者たちのおかげで考えが変わりました。確かに中国にはそういうこともありますが、私の考えでは、テレビで見せられるほど頻繁でも残酷でもありません。話しながら、私たち西洋の人間が中国について、そしてアジア全体についてどれほど多くの誤解を抱いているかを考えていました。こうした国はぜひ実際に訪れて、何が起きているのかを自分の目で確かめるべきです。テレビで中国がどれほどひどい場所かを聞くだけではいけません。少なくとも私の印象では、それは事実ではないからです。

数日後、ヨーロッパをたくさん旅したことのあるガイドの1人に、自分の印象を話しました。最初はカメラや警察が気になったけれど、数日で気にならなくなり、夜に1人で歩いても完全に安全だと感じた――イタリアのいくつかの都市ではほとんど考えられないことだ、と。社会信用スコアについても聞いてみました。彼女によれば、それは本当に存在するけれど、大きく下がらない限り気にしていないとのことでした。私は衝撃を受けました。彼女が批判すると思っていたのに、彼女にとってはごく普通のことだったのです。また、中国人は権力者やさまざまな制度について話したがらず、話すときも決して批判しないことに気づきました。それが彼女の意見の理由かもしれませんし、あるいは本当に気にしておらず、アメリカのクレジットスコアのようなものだと考えているのかもしれません。

::: note
**実際はどうだったのか：** 後で調べてわかったのは、国民一人ひとりに点数をつける全国統一のシステムは存在しないということです。いわゆる社会信用システムは、むしろ登録簿や「ブラックリスト」の集まりで、主に企業や、裁判所の判決に従わない人（たとえば借金を返済しない人）が対象です。こうした人たちには、たとえば航空券の購入などで制限がかかることがあります。一部の都市では地域独自のポイント制度が試されましたが、参加は任意です。ですから、クレジットスコアとの比較はまったくの的外れというわけではありません。ただし、これは大規模な監視がないという意味ではありません。私がいたるところで見たカメラは、紛れもなく本物です。
:::

### 万里の長城

この日は、北京中心部から北西に約55〜60kmの関所、居庸関への長いドライブで始まりました。中国で一番見たかった場所のひとつだったので、とてもわくわくしていました。唯一心配だったのは、時間がとても短いこと――約2時間で、どう考えても足りそうにありませんでした。でも、あるものでなんとかするしかありません。

バスを降りると、人々はすぐに買い物を始めました。まるで長城などどうでもよく、次のお土産だけが大事であるかのように。そしてもちろん、長城に登ったという証明書をもらうために。私には奇妙に感じられました。ほとんどの人はおそらく最高地点まで行かないのに、証明書は手に入れるのですから。

当時誰も教えてくれなかったのは、居庸関が要塞化された関所で、北から攻めてくる軍勢に対する重要な防衛拠点のひとつだったということです。場所はとても巧みに選ばれています。長城は両側の山の斜面を登り、その間に狭い峠があるので、守る側は谷の通行を支配することができました。ここでは1人で1万の敵を食い止められる、という言い伝えさえあります。誇張ではありますが、天然の守りがどれほど強固だったかがわかります。

私たちが聞かされたのは、頂上まで登るのに約1時間、下りもほぼ同じくらいかかるということだけでした。ぐるりと一周できることや、それにどれくらいかかるかは誰も言わず、ただスタートとゴールが同じ場所だということだけでした。そんな最低限の情報だけで、登山が始まりました。

長城は石でできていて、ところどころ階段がかなり急です。途中には兵士が詰めていた望楼があります。この区間は修復されたもので、古代とまったく同じ姿ではありません。実際、長城の多くの部分は何世紀にもわたって壊されては、必要に応じて再建されてきました。ある区間が使われずに荒れ果てた時代もあれば、戦略的な位置にあるために維持された区間もありました。居庸関の区間は1990年代に明代の様式にならって修復されました。

{% figure "images/china/IMG_20260505_092351.jpg", "長城からの眺め" %}

時間が足りなくなるのがとても心配だったので、ほとんど走るように登り、標高差350メートルを1時間ではなく25分で登りきりました。頂上に着くと、目の前に素晴らしいパノラマが広がりました。何より、向かいの丘が見えて、あそこまで行けるだろうかと考えたのです。とても遠く見えましたが、しばらく座って景色を楽しんだあと、挑戦してみることにしました。

{% figure "images/china/IMG_20260505_093437.jpg", "私がたどり着いた最高地点" %}

下りは速かったのですが、階段が登りよりもさらに急だったので、とても慎重にならなければなりませんでした。その間ずっと、時間が足りるかどうか心配していました。隣の丘の頂上に着いたとき、思っていたよりずっと近かったことに気づきました。約1時間半で長城のかなりの部分を歩き、残りの時間はただ景色と、石の龍の上を歩くという信じられない感覚を楽しみました。一周コースは約4.2kmで、何度も登り返す分をすべて含めると、累積標高差は約500mになります。

### 頤和園

長い散策のあと、頤和園に向かいました。中国史上最も象徴的な人物のひとり、西太后（慈禧太后）のお気に入りの場所です。大火のあと、彼女は海軍の近代化に充てるはずだった資金の一部を宮殿の再建に回し、その結果、中国はアヘン戦争に敗れたのだと聞きました。アヘン戦争については後でお話しします。

::: note
**実際はどうだったのか：** 資金流用の話には実際の根拠がありますが、戦争が取り違えられています。宮殿は1860年、第二次アヘン戦争の際にイギリス・フランス軍によって焼き払われました。つまり、アヘン戦争は再建の前にすでに敗れていたのです。西太后は1886年から海軍向けの資金を使って再建を進め、その数年後の1894〜1895年に、中国は日本との戦争に敗れました。正確な金額や、それがどこまで敗戦の原因になったのかについては、今も議論が続いています。
:::

一番印象に残ったのは、絵の描かれた長廊と石舫でした。長廊は長さ728メートルで、中国の神話や文学の物語、日常生活の場面を描いた14,000点以上の絵で飾られています。皇族は日差しや雨を避けながら、湖のほとりをここに沿って散策することができました。

石舫は1755年に造られた船の形をした石の楼閣です。西太后は1893年にこれを今の姿に再建しました。面白いことに、上の部分は木造で、大理石に見えるように塗装されています。そこにはある種の皮肉もあります。中国が本物の船を必要としていたときに、宮殿は決して航海できない船を手に入れたのですから！

### 天壇

翌日は天壇から始まりました。中国で最も重要な寺院のひとつで、1420年、紫禁城が建てられたのと同じ明の永楽帝の時代に建立されました。最も有名な建物である祈年殿は、金属の釘を1本も使わず、すべて木で造られています。ただし現在の祈年殿は、1889年に落雷で火事になり全焼したあとに再建されたものです。

ここは中国の皇帝が象徴的に天と交信する場所でした。皇帝は「天子」の称号を持ち、天と地の調和を保つことがその務めだと考えられていました。毎年、皇帝は特別な儀式を行い、雨や好天、豊作を祈りました。干ばつや飢饉、災害が起これば、人々はそれを皇帝が天の加護を失ったしるしと受け取ることもありました。

### 中国伝統医学の病院

前にも書いたように、中国人は伝統医学を強く信じていて、多くの人にとってそれは最良の治療法です。面白いことに、その薬草や療法の一部には治療効果があることが証明されている一方で、まったく効果がないと証明されたものも多く、それでも処方され続けています。

天壇のあと、伝統医学の病院に連れて行かれ、脈をとったり、虹彩や舌を診たりして「診断」を受けました。こうした方法で病気を見つけられることを科学はまだ裏付けていませんが、人々はそれを信じていて、よくこうした検診を受けに行きます。足のマッサージもしてもらいましたが、前日に長城を歩いたあとだったので、特に気持ちよかったです。

気に入らなかったのは、診断のあと、効果のはっきりしない、何にでも効くという薬を――しかもかなりの値段で――勧め始めたことです。長期間飲み続けなければならないもので、最初の分を飲み終わらないうちから、次の分をどうやって手に入れるかという話になっていました。これらの薬には変わった材料がいろいろ入っていることも、私には奇妙に思えました。

ガイドの1人は、COVID-19のときに中国でなぜあれほど多くの人が病気になったのかまで説明してくれました。彼によれば、人々が新しいウイルスの治療法を見つけてくれるはずの伝統医学にこぞって頼ったものの、古い療法は効かなかったからだそうです。

::: note
**実際はどうだったのか：** 中国で最大の感染の波が来たのは2022年末、「ゼロコロナ」政策が2022年12月7日に突然解除された直後です。ウイルスは自然免疫をほとんど持たず、高齢者のワクチン接種率も低かった人々の間に、数週間で広がりました。伝統医学が広く使われているのは確かですが、それが感染の波の原因だったわけではありません。
:::

### ヒスイ（玉）工場

中国はヒスイ（玉）で有名で、中国人によれば、本物のヒスイ、シルク、お茶は中国でしか買えず、世界のそれ以外のものはすべて模倣品だそうです。模倣品で有名な国でそれを聞くのは、なかなか面白いものです。

::: curious
もうひとつ皮肉な話があります。今日、中国市場に出回る緑の軟玉（ネフライト）の多くはカナダやロシアで採掘されたもので、世界の高品質な硬玉（ジェダイト、もうひとつの「ヒスイ」と呼ばれる石）の70%以上はミャンマー産です。中国で今も最も珍重されているのは、新疆のホータン（和田）産の白い軟玉です。
:::

店はショッピングモールの中にあってなかなか面白かったのですが、一番印象に残ったのは「世代の球」でした。たくさんの穴があいたヒスイの球で、その中に自由に動く小さな球がいくつも入っていて、すべてがひとつの石から彫り出されています。内側の球はそれぞれ家族の一世代を象徴し、全体で団結と幸福、世代間の絆を表しています。中国ではこれを「鬼工球（悪魔の細工の球）」とも呼びます。人間の手で彫れるとはとても思えないからです。

内側の球の数が多く、彫刻が美しいほど値段が高くなり、家に幸運をもたらすと信じられています。球の両側に中国の守護獅子があしらわれたものもあり、その場合は「双獅戯球（2頭の獅子が球で遊ぶ）」と呼ばれます。

## 鄭州

ヒスイの店のあと、少林寺へ向かう高速鉄道に乗るため駅に向かいましたが、その前に鄭州を通らなければなりませんでした。鄭州は中国で最も古い都市のひとつで、約3,500年前には殷（商）王朝の都のひとつでしたが、今ではとても近代的に見えます。街を見て回ることはできませんでしたが、高層ビルが立ち並んでいて、散歩にはとても良さそうな場所だと感じました。

この列車をリニアモーターカーのようなものだと想像しているなら、それは違います。外から見るとふつうの列車ですが、時速300kmで「しか」走りません。面白いことに、ブルガリアの列車でおなじみのガタガタという揺れはまったくなく、車内はとても静かで、これまでの長い日々の疲れを癒やすのに最適でした。出発前、あの速度だと外の景色はすべてぼやけて見えると言われていましたが、それは線路のすぐそばの木々だけの話で、遠くのものはふつうの列車から見るのとまったく同じに見えます。全体として、こうした列車こそ、世界中の列車がそうあるべき姿――速くて信頼できるもの――です。

::: curious
中国は世界最大の高速鉄道網を持っています。2025年末にはすでに50,000kmを超え、他のすべての国を合わせたよりも長くなっています。
:::

北京を出るとき、新しい建物がとても多いことに気づきました。高層住宅が立ち並ぶ団地がまるごと、空っぽに見えたのです。そばには道路があるのに、人も車もなく、まるでゴーストタウンのようでした。話には聞いていましたが、実際に見てこれほど驚くとは思っていませんでした。中国の建設のスピードはとても速く、新しい地区や、ときには都市全体が最初は空っぽのまま造られ、少しずつ人が住むようになります。でも近くに仕事がなければ、そうした場所での暮らしは大変です。

住宅について聞いた話にもとても驚きました。中国人は家を買いますが、本当の意味で完全に所有しているわけではなく、国から70年間借りているのだそうです。その後、相続人のためにもう一度だけ40年延長できるとのこと。土地の所有者は国のままで、国はいつでも人々を同じ価値の別の住宅に移し、土地を別の目的に使うことができます。新しい都市や地区に住む人の多くは、そうした手続きの結果そこに移ってきたか、単にそこが手の届く唯一の住宅だったのだろうと思います。

::: note
**実際はどうだったのか：** 中国の都市部では土地が国のものであり、購入者が70年間の土地使用権を得る（住宅そのものは購入者のもの）というのは本当です。ただ、「もう一度だけ40年」という話は正確ではありません。中国の民法典によれば、住宅用地の使用権は期限が来ると自動的に更新され、40年というのは商業・観光用地の最長期間であって、住宅用ではありません。更新の際に何を支払う必要があるのかは、まだ定められていません。
:::


## 登封

登封はカンフーの街だと言えるでしょう。中国の基準では小さな街で、人口は約70万人ですが、武術学校が約100校あると聞きました。（後で調べたデータでは40〜60校ほどですが、そこで学ぶ生徒は5万人を超え、最大の塔溝武術学校だけでも数万人が在籍しています。）ですから、誰かが少林寺で修行したと言ったら、おそらくこうした学校のどれかで修行したということです。

でも、そこが楽な場所だと思ったら大間違いです。朝6時から少年たちの掛け声が聞こえ始め、街中に響いているような気がしましたが、誰も特に気にしていないようでした。通りを歩くと、どこも上に有刺鉄線を張った高い塀に囲まれていて不思議な感じがしました。聞いたところでは、それは誰かが入ってこないようにするためではなく、中にいる少年たちが外に出ないようにするためだそうです。何と言うべきか――これが規律というものです。数か月から数年そこに入り、まるで刑務所のような生活を送り、することといえば1日10時間、完全に疲れ果てるまで訓練することだけ。映画で見るような、山の岩の上で僧侶が瞑想しているイメージとは違い、むしろ規律を身につけるための現代的な方法なのです。でも、それを乗り越えた人は、のちに兵士や警察官、俳優、ボディーガードになることができます。

{% figure "images/china/IMG_20260507_082456.jpg", "少年たちの訓練" %}

食事のスタイルもとても面白く、約10人がけの丸テーブルで、中央部分が回転するので、誰でも欲しいものに手が届くようになっていました。私たちは外国人なので、料理はあまり辛くなく、西洋人の口に合うように調整されていて、ナイフやフォークまでありました。料理が少なかったりおいしくなかったりしたと思う人がいたら、それは大間違いで、とてもおいしかったです。鶏の足のように私たちには珍しすぎるものが出ることはめったにありませんでした。ほとんどの料理は珍しいけれどおいしく、自国の中華料理店で食べるものにかなり近いものでした。

{% figure "images/china/IMG_20260506_184910.jpg", "回転テーブルのある丸テーブル――みんなが少しずつ取り分けます" %}

::: curious
私たちが中華料理店と結びつけて考える回転テーブルは、実はそれほど古い中国の発明ではありません。似たような回転盆は18世紀にはすでにヨーロッパにあり、中華料理店で広く使われるようになったのは1950〜60年代になってからです。
:::

### 音楽ショー「禅宗少林・音楽大典」

少林寺そのものを訪れる前に、素晴らしいショー「禅宗少林・音楽大典」を見ておくのはとても良い考えです。2007年から、少林寺から約7km離れた嵩山の美しい渓谷で上演されていて、伝統楽器による禅仏教の音楽と武術の演武を組み合わせたものです。音楽を手がけたのは作曲家の譚盾で、「グリーン・デスティニー」の音楽を作曲し、アカデミー賞を受賞したのと同じ人物です。断崖を前に座って、岩肌にじかに実物大で造られたステージのあちこちを何百人もの演者が動き回るのを眺め、レーザーが絵を描き、照明で崖がときに生きているように見える――本当に忘れられない体験です。機会のある方にはぜひおすすめします。中国人はスケールと細部で人を感動させる術を知っているのです。

### 少林寺

ここは数えきれないほどの映画に登場する場所で、カンフー映画の主人公のほとんどが何らかの形でここと関わっています。僧侶たちの修行の場面がいつも映し出されるので、少林寺は巨大で、少なくとも数千人はいて、とてもたどり着くのが難しい場所にあるのだと思い込んでしまいます。でも実際はそうではありません。アスファルトの道路で行けますし、恐ろしい断崖を期待していると、がっかりするでしょう。中にはかなり手入れの行き届いた小さな庭があります。遠くに山々が見え、いつか必ず訪れなければなりませんが、今回は寺を見て回るだけで満足するしかありませんでした。

### 龍門石窟

午後は洛陽近郊の龍門石窟（「龍の門」）に行きました。とても面白い場所で、ブルガリアのアルディノ近くにある「鷲の岩」を少し思わせますが、こちらの壁龕には仏像が収められています。伊河沿いを歩くと、まわりのいたるところに彫刻の収められた壁龕があります。石窟と壁龕は合わせて2,300以上、仏像は約11万体にのぼり、5世紀末から8世紀半ばにかけて彫られました。中国仏教美術の最高峰のひとつで、ユネスコ世界遺産にも登録されています。ある場所には巨大な彫刻群があって、ただただ圧倒されます。中央の仏像は高さ17メートルです。

残念ながら、多くの仏像が損傷しています。主に風化によるものだと思っていましたが、後で知ったところでは、損傷の大部分は人の手によるもので、20世紀初めに多くの頭部やレリーフが切り取られ、世界中のコレクターや博物館に売られたのだそうです。

## 西安

また列車に揺られて、中国の古都・西安に着きました。何世紀にもわたって10を超える王朝がここから国を治め、唐の時代にはこの街（当時は長安と呼ばれていました）は世界最大級の都市のひとつで、シルクロードの起点でもありました。今日の西安は兵馬俑のおかげで観光で知られていますが、中国の大きな工業都市のひとつでもあります。とても気に入ったのですが、残念ながら見て回る時間が足りませんでした。わずかに見ただけでも、強く印象に残りました。

### 大雁塔

朝は、中国で最も重要な仏教遺跡のひとつ、唐の時代の652年に建てられた大雁塔から始めました。孫悟空とその冒険を描いた映画はたくさん見てきましたが、面白いことに、それらは僧・玄奘の実際の旅に基づいています。

7世紀、玄奘は中国からインドへの非常に危険な旅に出て、それは約17年に及びました。彼は600部以上の仏教経典を持ち帰り、それを中国語に翻訳し始めました。この塔は、まさにそれらの経典を安全に保管するために建てられたのです。彼の旅はのちに有名な中国の小説「西遊記」の着想源となり、そこに伝説の猿の王、孫悟空が登場します。

塔はとても美しく、訪れる価値は十分にありますが、これはまだ一日の始まりにすぎませんでした。この先に、私たちが西安に来た本当の理由が待っていたのです。

### 始皇帝陵と兵馬俑

陵墓の前に、現代の兵馬俑やその他の美術品を作っている店を訪れました。素晴らしい店で、博物館として見ても十分なほどでした。

{% figure "images/china/IMG_20260508_111038.jpg", "店に並ぶ手刺繍の屏風" %}

秦の始皇帝は、紀元前221年に中国を統一し、最初の皇帝となった人物です。陵墓そのものはいまだに発掘されておらず、近いうちに発掘されることもおそらくないでしょう。計り知れない財宝が眠っていると考えられていますが、古代の記録によれば陵墓の中には水銀の川が流れているとされ――実際、測定でも土壌中の水銀濃度の高さが確認されています――発掘は非常に危険です。中国政府は、すべてを後世のために保存できる技術が整うまで、陵墓を発掘しないことに決めています。

兵馬俑は1974年、井戸を掘っていた農民によってまったくの偶然で発見されました。坑には兵士、馬、戦車などの実物大の土の像が8,000体以上あり、出陣の隊形で並んで、皇帝の陵墓とあの世への道を守っていると聞きました。実際には、8,000というのは坑全体の推定数で、これまでに発掘されたのは約2,000体、残りはまだ地中に眠っています。とても興味深かったのは、ところどころで像がビニールシートで覆われていたことです。理由は、像がかつて彩色されていたからで、空気が塗料に触れたとたんに劣化が始まり、下地の漆は数秒で縮み、数分ではがれ落ちてしまうのです。そのため、色をできるだけ残そうと、少しでも塗料が見えるとすぐに覆うのだそうです。

また、無傷で見つかった像がほとんどないというのも興味深い点です。坑の屋根が崩れ落ち、土の重みで像が粉々になったため、あとから組み立て直さなければなりません。ひとつの場所に複数の像の破片が混ざっていることもあり、パズルはとても複雑になります。

### 西安のイスラム街

:::

### 歌舞ショー「唐王朝」

長い一日のあと、中国版「ムーラン・ルージュ」と紹介された素晴らしいショーに行きました。「唐王朝」は西安で最も美しい公演のひとつで、音楽、舞踊、豪華な衣装、伝統楽器によって、約1,300年前の宮廷生活を再現しています。

シルクロードを通って、ペルシャやインド、中央アジアから商人や音楽家、旅人たちがこの都にやって来ました。そのためショーには、中国文化だけでなく他の文化のモチーフもたくさん盛り込まれています。

一番印象に残ったのは、長い絹の袖を使った美しい舞でした。歴史に着想を得たものですが、残念ながら舞そのものは古代から伝わってはいません。20世紀に中国の芸術家や振付師たちが古代の壁画や彫刻、文献を研究し、唐の時代の舞のイメージを復元し始めたのです。

{% figure "images/china/IMG_20260508_195748.jpg", "長い絹の袖をまとった舞姫たち" %}

私にとっては、まるで映画「グリーン・デスティニー」の中に入り込んだようでした。目の前では信じられないような舞が繰り広げられ、伝統楽器で伝統音楽が奏でられ、私たちは中国の餃子をつまんでいたのです。間違いなく忘れられないひとときでした。

## 桂林

すっかり疲れ果てたこの冒険のあと、私たちは南へ飛びました。美しい自然と穏やかな雰囲気で知られる中国の一地方です。私たちにとっては休暇のようなもので、これまでに見て体験したことをすべて消化する時間、物事がもっとゆっくり穏やかに進む時間でした。その後の数日間は、まるで過去にタイムスリップしたような気分で、大都市のあとでは心地よい変化でした。

{% figure "images/china/IMG_20260509_091139.jpg", "飛行機の窓から見た中国の田園風景" %}

桂林という名前は、文字どおり「キンモクセイの森」を意味します。キンモクセイは小さな花が甘い香りを放つ芳香のある木で、中国の人々はその花からお茶やお菓子、香りのよい飲み物を作ります。秋、キンモクセイが咲くと、街全体がその香りに包まれます。

{% figure "images/china/scale_1200.jpg", "キンモクセイの花" %}

桂林は、平野からほぼ垂直にそびえる信じられないような石灰岩の山々、漓江、そして古い中国の村々で有名です。中国にはよく知られたことわざがあります。

> 「桂林の山水は天下一」

ブルガリアのほとんどの人はこの場所を聞いたこともありませんが、それは残念なことです。中国の人々にとっては、休暇や散策にお気に入りの場所のひとつなのですから。

### 蘆笛岩

最初の目的地は蘆笛岩でした。その名前は、入口のまわりに生える葦に由来していて、かつてはそれで笛が作られていました。何も知らずに行ったのですが、とてもうれしい驚きでした。中にはさまざまな色にライトアップされた鍾乳石や石筍がたくさんあり、宮殿や滝、空想上の生き物のように見えるものもあります。

洞窟の壁だけでも、墨で書かれた詩や旅の記録など、70以上の古い銘文があります。最も古いものは唐の時代の792年のものです。その後、洞窟は何世紀にもわたって忘れ去られ、1940年代に日本軍から逃れた避難民がここに隠れたことで、ようやく再発見されました。

### 陽朔へ

翌日、その夜を過ごす小さな町、陽朔へ向けて出発しました。道中、ガイドが中国についてもう少し話してくれることになりました――ただし今回は、豊かな大都市の視点ではなく、農家で育った人の視点からです。

### 中国の働き方について知ったこと

中国の人がどれくらい休暇をとれるのか何度か尋ねましたが、みんな言うことが違ったので、自分で調べてみることにしました。実情は以下のとおりです――ただし、仕事の内容や雇用主、省によっても変わります。

::: note
中国では、有給休暇の日数は通算の勤続年数によって決まります。
- 通算勤続1年未満――通常、法定の休暇の権利はありません。
- 1年以上10年未満――5日。
- 10年以上20年未満――10日。
- 20年以上――15日。

さらに2025年からは、中国の法定祝日は年13日になりました（それまでは11日でした）。
:::

標準的な労働時間はブルガリアと同じく週5日・1日8時間で、通常の制度では残業は月36時間までに制限されています。私たちがみな聞いたことのある話の多くは、もはや事実ではないか、実際に起きているとしても完全に合法とは言えないものです。

行く前は、みんなが噂に聞いていた「996」で働いているのだと思っていました。名前は「朝9時から夜9時まで、週6日」に由来します。この働き方は、中国のインターネット企業やIT企業で知られるようになりました。

2021年8月、中国の最高人民法院は人的資源・社会保障部とともに、「996」の強制は違法だと明言しました。それでもこの働き方は完全にはなくなっておらず、競争や雇用主からの圧力、もっと稼ぎたいという思いから、長時間働き続ける人もいます。

本当に驚いたのは、中国人が35歳になるのを恐れていることです。「35歳の呪い」という言葉まであるほどです。35歳になったとたん、毎日、上司に呼び出されてクビを言い渡されないかと心配し始め、そうなると新しい仕事を見つけるのはとても難しくなる、と聞きました。

理由はいくつかあります。
- 若い社員のほうが給料が安いことが多い。
- 雇用主は、若い人のほうが長時間労働を受け入れやすいと考えている。
- 35歳以上の人は、たいてい家族への責任が大きい。
- IT企業は常に新しいスキルを求めている。
- 資格が同程度でも、若い候補者を好む雇用主がいる。

ちょうどこの年齢でリストラの対象になった社員の事例や、年齢の上限を35歳とする求人広告も記録されています。長いあいだ、35歳は公務員試験の受験年齢の上限でもありました。2025年になってようやく38歳（修士・博士の学位を持つ人は43歳）に引き上げられたのです。

ただし、中国には35歳になった人を自動的に解雇できるとする法律はなく、雇用主が契約を解除するには法的な根拠が必要だということは言っておかなければなりません。

こうしたことには驚きました。私が中国について想像していたこととは違ったからです。良いのは、状況が少しずつ改善し、奇妙で非倫理的な慣行がなくなりつつあることです。

### 漓江下り

長い移動のあと、いよいよ船に乗って景色を楽しむ時間です。前にも書いたように、ここは中国の人々のお気に入りの場所のひとつで、あまりに好きなので20元札にまで描かれています。

{% figure "images/china/20_yuan.jpg", "20元札――裏面には漓江沿いの断崖が描かれています" %}

乗船を待っている間、変わった、でもとても美しい衣装を着た女の子たちが何人かいることに気づきました。後で知ったのですが、その衣装はこの地域の少数民族のひとつ、ミャオ族（苗族）のものでした。翌日、私は地元の少数民族の暮らしにもっと身近に触れることになります。

### ショー「印象・劉三姐」

夜はショー「印象・劉三姐」を見に行きました。演出は張芸謀――2008年北京オリンピックの開会式を演出したのと同じ人物――で、2004年から上演されています。600人以上が出演していて、そのほとんどは昼間は別の仕事をしていて、夜になると技を披露しにやって来る地元の人たちです。舞台は川そのもの――約2kmにわたる漓江――で、背景にはライトアップされた12の石灰岩の山々が並び、演技の多くは船の上で行われます。個人的には他のショーのほうが印象に残りましたが、このショーにも独自の魅力があり、見る価値は十分にあります。地元の漁師や農家、その他の働く人たちがこれほど息の合った演技をしていると思うと、ただただ驚かされます。

### 龍脊棚田

翌日は、有名な龍脊棚田――「龍の背骨」――に向かいました。映画で何度も見ていたので、山全体がまるごとこうして耕されているのだと想像していました。実際はそれほど巨大ではありませんでしたが、それでもとても興味深い場所でした。村の小道を歩くので、しっかりした靴が絶対に必要です。棚田の中を歩きたいなら、泥んこになる覚悟をしておいてください。

棚田がこれほど山の高いところにあるのは、中国の歴史のさまざまな時代にいろいろな民族が迫害され殺されたため、避難先を求めて山に住み着いた人々がいたからだと聞きました。しかしそこには食べていくだけの土地がなかったので、こうした棚田を造り始め、そこで米を育てたのです。標高が高いため米作りは難しく、広大な面積が必要だったので、世代を重ねるごとに棚田は広がり、今の姿になりました。造成が始まったのは約700年前の元の時代で、完成したのは清の時代の初めになってからです。この一帯にはチワン族やヤオ族の村がいくつかあり、それぞれ独自の建築、衣装、習慣を持つ少数民族です。

隣の黄洛村のヤオ族の女性たちは、とても長い髪で有名です。中には2メートルを超える人もいます。この村は「長髪の村」としてギネス世界記録にも認定されています。
:::

## 上海

中国の田舎を巡る心地よい旅のあと、再び大都市に戻り、そのなかでも最大級の都市、上海を訪れる時が来ました。私たちは飛行機で、国を数時間で横断して、経済の中心地のひとつへ向かいました。この街には長い歴史があり、中国人にとってはかなりつらい出来事に満ちていると聞きました――特にアヘン戦争の時代です。

::: note
アヘン戦争は、中国と欧米列強との間で起きた2つの戦争です。第一次（1839〜1842年）はイギリスと、第二次（1856〜1860年）はイギリス・フランスとの戦争でした。主な原因は、国民の間に広がる深刻な中毒を理由に中国が禁止しようとしていた、利益の大きいアヘン貿易をイギリスが続けたがったことです。中国は両方の戦争に敗れ、港を外国貿易に開放し、欧米諸国に特権を与え、香港をイギリスに割譲することを余儀なくされました。
:::

戦争のあと、上海は外国の租界に分割されました。中国人はそうした区域に入ることを禁じられ、もし入っても出てこられないことが多かったこと、そして多くの中国人が鉄道建設などの重労働のために他の国へ送られたことを聞きました。

::: note
**実際はどうだったのか：** 話はもっと複雑です。中国人は租界に入れただけでなく、住民の圧倒的多数を占めていました。1930年の国勢調査によれば、共同租界には100万人近くの中国人が住んでいた一方、外国人は上海全体の約4%を超えることはありませんでした。ただし中国人は二級市民で、長いあいだ租界の行政に自分たちの代表を送ることができず、公園のような場所にも使用人としてしか入れませんでした。中国人労働者が海外へ送られたのも事実で――たとえばアメリカで鉄道を建設しました――ですが、それは租界とは直接関係がありません。
:::

{% figure "images/china/IMG_20260513_102603.jpg", "上海の外国租界の地図" %}

ぞっとしたのは、イギリス租界の向かいに「犬と中国人入るべからず」と書かれた看板のある公園があったという話でした。調べてみると、1917年の看板の写真が見つかりましたが、そこにはまさにそのとおりの文言が書かれているわけではありません。

{% figure "images/china/bi-s079.jpg", "上海の公共庭園の利用規則を写した歴史的写真、1917〜1928年。ブリストル大学アーカイブ。" %}

規則によれば：

規則第1条：「庭園は外国人コミュニティ専用とする。」

規則第4条：「犬および自転車の入園を禁ず。」

つまり、ひとつの看板に中国人を締め出す制限と犬の禁止が本当に両方書かれていたわけです――ただし、別々の2つの条項として。

ところが1903年の古い規則では、中国人がはっきりと名指しされています。

> 外国人に付き添う使用人を除き、中国人の入園を禁ず。

この公園は数十年にわたってほとんどの中国人に閉ざされたままで、1928年にようやく規則が変更されました。現在その場所は外灘の黄浦公園になっていて、人民英雄紀念碑が立っています。

{% figure "images/china/BxSAgrdP8L98OpAe8W6AxUwyKPOi1DlrXSvbTkTbU9A.jpg", "1910〜1911年ごろの上海の公共庭園の入口。イギリス国立公文書館所蔵の写真、Virtual Shanghai掲載。" %}

この話を聞いて、中国人が西洋の人と接するときに少し控えめな理由がわかりました。彼らはそれほどの差別と人権侵害を経験してきたのです。ヨーロッパ人が長く暮らしていたため、上海はとても西洋的な雰囲気で、他の中国の都市とは違い、急速に工業化しましたが、その代償はとても大きなものでした。中国の薬物に対する極めて厳しい姿勢も、この時代に由来すると考えられています。

1990年代、浦東――今日私たちが目にする高層ビルのほとんどが建つ新しい市街地――の建設が始まりました。高層ビルが一か所に集まっているのはそのためです。旧市街は川の片側にしかなく、反対側には1990年まで主に畑と倉庫しかなかったのです。

### 朱家角

朝は、上海中心部から西へ約50kmのところにある古い水郷、朱家角に行きました。1,700年以上の歴史があり、美しい運河や石橋、古い家並みから、今では「上海のヴェネツィア」と呼ばれています。

今ではロマンチックな観光地に見えますが、何世紀も前はにぎやかな商業の中心地でした。運河は道路の役割を果たし、船が米や布、その他の品物を運んでいました。特に明・清の時代、朱家角は交易によって栄え、水辺の古い家々はかつて店や倉庫、裕福な商人の住まいでした。最も有名な橋である放生橋は1571年に架けられたもので、上海地域で最大の五連アーチの石橋です。

### 課植園

中国の庭園は日本の庭園に似ていると思っているなら、それは大きな間違いです！共通点はかなり多いものの、そこで感じるものはまったく違います。中国の庭園は、それほど厳密に整えられた完璧なものには見えません。もっと生き生きとして自然で、まるで誰かが自然の一部をちぎって街に運んできたかのようです。ここではすべてが自然体に見えます――岩も、木も、水も、曲がりくねった小道も。一方、日本の庭園は、細部まで考え抜かれ、すべてがあるべき場所にぴたりと置かれた精緻な芸術作品のようです。美しいのですが、私には時に完璧すぎて、少し生気がないようにさえ感じられます。**中国の庭園は自然の一部になるよう誘い、日本の庭園は自然を眺めるよう誘っているようです。**

::: curious
庭園の石のテーブルに刻まれているのを見た囲碁（中国語では「围棋（ウェイチー）」）は、中国でとても人気があります。チェスのような戦略ゲームですが、大きな違いがひとつあります。目的は相手の駒を取ることではなく、できるだけ広い陣地を囲むことなのです。このゲームは2,500年以上前に中国で生まれました。
:::

### 東方明珠電視塔に登る

中国での最終日は、楽しみにしていたことから始まりました。東方明珠電視塔の展望台に上ることです。高さは468メートルで、巨大な真珠を上下に連ねたような未来的な建造物に見えます。完成したのは、上海が世界で最も近代的な大都市のひとつへと変わり始めた1994年で、2007年までは中国で最も高い建造物でした。その形のアイデアは、唐の詩人・白居易の一節に由来しています。彼は琵琶の音を「大小の真珠が玉の皿に落ちる」さまにたとえたのです。

### 豫園

豫園は、伝統的な中国庭園の中でも最も美しいもののひとつです。上海の旧市街にあり、明の時代の1559年、官僚の潘允端が年老いた両親への贈り物として造りました。広さは約2万平方メートルで、楼閣や池、岩組み、曲がりくねった橋、次々と新しい景色が現れる細い小道でいっぱいです。本当に見る価値がありますが、心から楽しむには、腰を下ろして静けさと安らぎに身を委ねる必要があります――観光客がこれほど多い今日では、なかなか難しいことです。

::: curious
言い伝えによれば、ある人が皇帝に、潘家が皇帝だけに許された象徴である龍をあしらった塀を築いており、明らかに帝位を狙っていると密告しました。潘はいち早くそれを知り、龍の爪を「切り落として」皇帝の龍ではないようにしたそうです。そして有名な「玉玲瓏」という岩は実はヒスイではなく、太湖の石灰岩で、高さ3.3メートル、72の穴があいています。その下でお香を焚くと、すべての穴から一斉に煙が立ちのぼるのです。
:::

中国を訪れてから数か月が経ちました。滞在はたった11日間と短いものでしたが、体験と場所があまりに詰まっていて、自分がどこにいたのかを実感するには時間が必要でした。今、写真を見ながらいろいろな場所について書いていると、現地ではまったく考えもしなかった細部に気づきます。ある場所について読むことと、そこに行って体験することは確かに違いますが、それぞれに魅力があります。

帰ってきて友人たちに旅の話をすると、みんなに一番印象に残った場所はどこかと聞かれました。私にとってそれは、朝陽公園での夜――この国についての私のイメージをすっかり変えてくれた若者たちに出会った夜でした。そのすぐ後に続くのが万里の長城と兵馬俑です。今、写真を見ていると懐かしさがこみ上げてきます。素晴らしい冒険でしたし、必ずまた中国に行きたいと思っています。そのころには通りにロボットがいて、人々がもっと英語を話しているといいなと思います。

この記事を書いたのは、帰国後、多くの人が私の旅について読みたいと言ってくれたからです。文章を書くのは決して得意ではなく、ここまで書けるとは思ってもいませんでしたが、ご覧のとおり、勇気を出して書いてみました。すべての体験をひとつの記事に収めることはとてもできず、書ききれなかったことがたくさんありますが、楽しんでいただけたなら幸いです。これからも、世界をめぐる私の冒険の記事を読んでいただけたらうれしいです。
